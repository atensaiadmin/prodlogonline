# Phases

## v0 — Single-user MVP

**Goal:** The founder (you) can use it daily.

- Dashboard with ideas grouped by stage
- Quick-add idea (title only, 5 seconds)
- Idea detail page with entry timeline
- Add entry to an idea (freeform text)
- Change stage (dropdown or buttons)
- Set conviction score
- Tags
- Responsive (mobile-first)

**Non-goals:**
- Auth / multi-user
- AI features
- File uploads
- Public sharing
- Export

## v1 — Multi-user & polish

- Authentication (magic link or GitHub OAuth)
- Beautiful landing page + marketing site
- Public "profile" or shared board (opt-in)
- Markdown entry bodies
- Export to JSON / CSV
- Dark mode
- Keyboard shortcuts

## v2 — Founder-friendly extras

- Weekly digest email ("you have 3 ideas in inbox, 1 is stalling")
- Conviction trend chart
- Reminders for stale ideas (nudge after 2 weeks of no entry)
- Link ideas to external resources (GitHub repo, Notion doc, Figma file)
- Mobile app (PWA or native)

## v3 — Stretch

- Team mode (share an idea board with co-founder)
- AI: summarize log, suggest next action, flag stalled ideas
- Public "idea graveyard" (transparency, content marketing)
- API
